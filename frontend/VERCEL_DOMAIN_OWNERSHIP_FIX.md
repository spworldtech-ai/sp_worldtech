# spworldtech.com — Vercel Domain Ownership Fix

If Vercel shows:

> This domain is linked to another Vercel account. To use it with this project, add a TXT record at `_vercel.spworldtech.com` to verify ownership.

This is a **Vercel account/domain ownership issue**, not a frontend HTML/JavaScript problem. The project code cannot create or remove the verification TXT record.

## Correct fix

1. Open the Vercel project that should own `spworldtech.com`.
2. Open **Settings → Domains**.
3. Add `spworldtech.com` (and `www.spworldtech.com` if needed).
4. If Vercel gives the domain-ownership verification prompt, copy the **exact TXT value generated by Vercel**. Do not invent a value.
5. At the DNS provider that currently manages `spworldtech.com`, create:
   - Type: `TXT`
   - Name/Host: `_vercel`
   - Value: **the exact verification value Vercel gives you**
   - TTL: the provider default or a short TTL while verifying
6. Wait for DNS propagation, then return to Vercel and verify the domain.
7. After Vercel confirms ownership, follow the domain page's exact A/CNAME records. Remove stale/conflicting Vercel records only after confirming what the active project requires.

### Important

Do not add a guessed TXT value. The verification token is unique to the Vercel account/project. If the old Vercel account is still yours, transferring the domain from that account is another valid route.
